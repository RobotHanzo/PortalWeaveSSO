Short description:
OAuth and OpenID Connect sign-in with account mapping, access controls,
SCIM provisioning and local audit reports.

Suggested additional information for the review team:
PortalWeave SSO is a complete, source-readable OAuth/OIDC client. All modules
are included without paid unlocks, developer accounts, trial limits or remote
code downloads. The administrator configures the actual identity service;
external service requests, personal-data handling and provider policy links
are documented in readme.txt and four bundled user guides. Please see the
accompanying REVIEWER-NOTES.txt for security boundaries, setup and the
reviewed Plugin Check warnings. No real credentials are included.
