PortalWeave SSO branding
======================

logo.png (128 x 128) and logo@2x.png (256 x 256) are transparent PNG
exports of the original PortalWeave SSO interwoven portal mark, created
with image generation from the project's own design brief on 2026-11-07.
They contain no third-party provider marks.

These project artwork files are distributed under the plugin's
GPL-2.0-or-later license; see the LICENSE file in the plugin root.

The settings header serves these files locally. Beside the visible product
name the image is decorative and has empty alternative text.

Artwork masters and WordPress.org listing exports are maintained outside
the runtime package in docs/branding/ and .wordpress-org/ respectively.
